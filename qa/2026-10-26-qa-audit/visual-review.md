# Visual review, final working-tree build

78 Release PNGs were inspected using full-size views for dense/compact areas and contact sheets
for repeated settings pages and the face/scale/state matrix. Settings rows, labels, paging and
values are within the rendered editor at both minimum and maximum scales. No hidden page was
accepted solely from code. See visual-review.json for the exact reviewed images and hashes.

Observed limitations remain explicit: vertical single mode has the wrong secondary lamp layout;
Arc/horizontal single companion layouts still need final design acceptance; lit Overs and all
visibility/type combinations were not captured. The fonts and dense captions are small technical
meter type; no user aesthetic acceptance is inferred. Native mouse/popup/keyboard interaction is
unverified and is described separately in native-ui.md.

The primary face render checks apply to the default dual-channel faces. The settings pages have
neutral slate colours, scale uniformly, and expose the 55 existing parameters. They are full
component renders, not proof of popup placement or operation in a DAW.
